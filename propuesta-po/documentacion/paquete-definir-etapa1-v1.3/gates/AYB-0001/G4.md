# Envio de gate - G4 - Definition of Ready

acto formal es el correo; este documento va adjunto. El gate cuenta como aprobado solo cuando este

sellado), por un PR aprobado por el CODEOWNER del rol. Cada DoR, además, lo firman en Nexora el
